## Instructions

1. **Extract the ZIP File**

   * Extract the contents of the ZIP file to the `D:\` drive.

2. **Open the Project**

   * Navigate to `D:\Hills`.
   * Open the `Hills.cbp` file using [Code::Blocks](http://www.codeblocks.org/).

3. **Build and Run**

   * In Code::Blocks, click **Build** to compile the project.
   * Click **Run** to execute the program.

> 💡 Make sure Code::Blocks is installed and set up with a suitable compiler (e.g., MinGW for Windows).

## How to Play

### Scene 1

* Click the **left mouse button (LMB)** to start the first scene.
* After the car drives off the screen, press **J** to transition to the next scene.

### Scene 2

* Click **LMB** again to start this scene.
* When night falls and the bonfire starts, look at the boy’s pocket — you’ll see a **phone notification symbol**.
* Press:

  * **I** to view the first message.
  * **O** to view the second message.
  * **P** to view the final message.
* After reading all the messages, press **J** to continue to the next scene.
